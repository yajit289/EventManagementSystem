# 🎓 CampusConnect – College Event Management System

CampusConnect is a full-stack web application designed to simplify the management of college events. It provides a centralized platform where students can explore, register, and stay updated about campus activities, while administrators can efficiently create and manage events.

---

## 🚀 Features

### 👨‍🎓 Student Features

* Browse all upcoming events
* Register for events
* View event details (date, time, venue, description)
* Receive updates and notifications

### 🛠️ Admin Features

* Create, update, and delete events
* Manage event registrations
* View participant lists
* Dashboard for event tracking

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/campusconnect.git
cd campusconnect
```

### 2️⃣ Setup Backend

```bash
cd server
npm install
npm start
```

### 3️⃣ Setup Frontend

```bash
cd client
npm install
npm run dev
```

---

## 🔐 Environment Variables

Create a `.env` file in the server folder and add:

```
PORT=5000
DB_URI=your_database_connection_string
JWT_SECRET=your_secret_key
```
